What the program does (one line each)

1. Load companies, destinations and offers from files.
2. Check the data. Bad rows go to a log, not into the program.
3. Ask the traveller for a request (route, dates, budget, and so on).
4. Remove offers that break hard rules (filter).
5. Score the rest with weights (rank).
6. Show the ranked list and explain the top offer.
7. Let the traveller book one offer
